# 🤖 Shifra - Virtual AI Assistant

Shifra is a sleek, futuristic, voice-activated virtual assistant web application built using **HTML, CSS, and JavaScript**. It features a modern cyberpunk-inspired user interface with glowing neon visual elements and uses native Web APIs to respond to real-time voice commands.

---

## ✨ Features

* **🎙️ Voice Recognition:** Uses the native browser `Web Speech API` to listen to user input through the microphone.
* **🗣️ Text-to-Speech (TTS):** Shifra replies out loud with audio responses customized in pitch and speed.
* **🌌 Cyberpunk UI:** A fully dark-themed interface utilizing neon text drop-shadows, an illuminated gradient action button, and pulsing animations.
* **🛠️ Practical Web Automation:** Programmed to open common websites (Google, YouTube) and report current time or date metrics instantly.

---

## 🛠️ Technology Stack

* **HTML5:** Structured semantic layouts.
* **CSS3:** Custom linear gradients, keyframe animations (`pulse` and `float`), and advanced neon blur properties (`drop-shadow`/`text-shadow`).
* **Vanilla JavaScript:** Event handlers, command processing matrices, and integrations with the browser's web speech engines.
